# TRUVEX EXIM Website

Responsive multi-page corporate website based on the supplied TRUVEX EXIM presentation.

Pages: Home, About, Products, Materials, Solutions, Contact/Enquiry.

Before publishing, edit `config.js` and add the real company:
- WhatsApp/phone number
- display phone
- email

The presentation did not provide phone/email/website details, so these are intentionally blank.

The enquiry form routes to WhatsApp or email after configuration. A backend/database can be connected later for stored enquiries.
